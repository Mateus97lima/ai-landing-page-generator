# ⚡ Gerador de Landing Pages com IA
 
> Descreva seu negócio e a inteligência artificial cria uma landing page completa em segundos.
 
🔗 **[Acessar o projeto](https://ai-landing-page-generator-livid.vercel.app)**
 
---
 
## 💡 Sobre o projeto
 
Projeto desenvolvido para praticar e aprimorar lógica de programação e integração com APIs de inteligência artificial.
 
O usuário descreve um negócio no campo de texto — ou escolhe uma sugestão rápida — e a IA gera automaticamente uma landing page completa em HTML e CSS, exibindo o código e o preview em tempo real.
 
---
 
## ✨ Funcionalidades
 
- ✅ Geração de landing page completa com um prompt
- ✅ Sugestões rápidas de negócios
- ✅ Preview em tempo real da página gerada
- ✅ Visualização do código HTML gerado
- ✅ Copiar código com um clique
- ✅ Download do HTML gerado
- ✅ Abrir preview em fullscreen
- ✅ Contador de páginas geradas e tempo de resposta

| Tecnologia | Uso |

## 🚀 Como rodar localmente
 
```bash
# Clone o repositório
git clone https://github.com/Mateus97lima/gerador-de-paginas-de-destino-com-ia.git
 
# Entre na pasta
cd gerador-de-paginas-de-destino-com-ia
 
# Instale as dependências
npm install
```
 
Crie o arquivo `.env.local` na raiz com:
```
GROQ_API_KEY=sua_chave_aqui
```
 
Obtenha sua chave gratuitamente em [console.groq.com](https://console.groq.com)
 
```bash
# Rode em desenvolvimento
npm run dev
